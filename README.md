# بازی کانتکت (Contact) 🎮

بازی چندنفرهٔ حدس کلمه با WebSocket — بدون هیچ وابستگی خارجی به‌جز `ws`.

## نصب و اجرا

```bash
npm install
npm start
# سپس در مرورگر: http://localhost:3000
```

## قوانین بازی

1. **ساخت اتاق**: میزبان اتاقی با کد ۴ حرفی می‌سازد (حداکثر ۱۲ بازیکن).
2. **تعیین کلمهٔ مخفی**: فقط میزبان کلمه (حداقل ۲ نویسه) را تعیین می‌کند. مقدار کلمه هرگز به بازیکنان دیگر فرستاده نمی‌شود.
3. **شروع بازی**: اولین حرف کلمه آشکار می‌شود (مثلاً «ک....»).
4. **دادن سرنخ**: هر بازیکن می‌تواند سرنخی (کلمه یا عبارت مرتبط با کلمهٔ مخفی) بنویسد.
5. **اتصال**: بازیکنی غیر از نویسندهٔ سرنخ اگر فهمید منظور سرنخ چیست، دکمهٔ «اتصال» را می‌زند؛ شمارش معکوس ۵ ثانیه‌ای authoritative سمت سرور آغاز می‌شود.
6. **حدس قطع اتصال (فقط میزبان)**: تا پیش از پایان شمارش، میزبان می‌تواند حدس بزند سرنخ به چه کلمه‌ای اشاره دارد:
   - درست ⇒ آن سرنخ **می‌سوزد** و دور ریست می‌شود.
   - نادرست ⇒ خطا برمی‌گردد و بازی ادامه دارد.
7. **فاز پاسخ کور**: با پایان شمارش، نویسندهٔ سرنخ و وصل‌کننده هرکدام باید کلمهٔ مخفی را بنویسند:
   - **یکسان** ⇒ یک حرف از پیشوند آشکار می‌شود و دور ریست می‌گردد.
   - **متفاوت** ⇒ دور ریست می‌شود بدون پیشرفت.
8. با آشکار شدن کل کلمه، پیروزی اعلام می‌شود. میزبان می‌تواند دور را ریست (`restart_round`) یا بازی را تمام (`end_game`) کند.

## نرمال‌سازی

ی/ي و ک/ك یکسان، اعراب و تشدید حذف، نیم‌فاصله (ZWNJ) و فاصله‌های اضافی پاک/یکسان‌سازی می‌شوند؛ حروف فارسی کاملاً حفظ می‌شوند.

## تب دوم برای تست

دکمهٔ «باز کردن تب دوم» در صفحه، همان URL را در تب جدید باز می‌کند (در همان مرورگر دو بازیکن مستقل شبیه‌سازی می‌شود).

## نکات تولید (Production Caveats)

- `ws` بدون TLS است؛ در تولید حتماً پشت reverse proxy با wss:// قرار دهید.
- اتاق‌ها در حافظه‌اند؛ با ری‌استارت سرور از بین می‌روند. برای پایداری از Redis/DB استفاده کنید.
- ری‌کانکت خودکار WebSocket پیاده نشده؛ کلاینت باید room/join را دوباره انجام دهد.
- نرخ ارسال پیام (rate-limit) و احراز هویت اضافه نشده است.
- برای استقرار واقعی، PORT را با متغیر محیطی `PORT` تنظیم کنید (پیش‌فرض 3000).
